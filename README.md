# Rechenweg – Lösungsarchiv Informatik

Ausführlich gerechnete Lösungsvorschläge zu den Übungsaufgaben der ersten Semester im Informatik-Studium. Jeder Schritt ist begründet, und jedes Beispiel gibt es auch als PDF.

| | |
|---|---|
| **Begonnen** | Anfang 2023 |
| **Fertiggestellt** | 30. September 2025 |
| **Zuletzt aktualisiert** | 20. November 2026 |
| **Status** | Abgeschlossen (Endstand) |

> **Keine Garantie auf Richtigkeit.**
> Alle Lösungen sind selbst erarbeitet und können Fehler enthalten. Sie sind zum Vergleichen und Verstehen gedacht und ersetzen keine offizielle Musterlösung.

## Werkzeuge

- **Karteikarten** ([`karten.html`](karten.html)): alle Sätze und Definitionen als Lernkarten mit Leitner-Fächern
- **Prüfungsmodus** ([`pruefung.html`](pruefung.html)): zufällige Beispiele mit Timer, danach Selbstbewertung
- **Termine** ([`termine.html`](termine.html)): Archiv der Tests, Prüfungen und Abgaben
- **Suche**: mit `/` auf jeder Seite, nach Nummer oder Stichwort

## Struktur

```
index.html          Startseite / Übersicht
<kurs>/index.html   Kapitelübersicht je Lehrveranstaltung
<kurs>/beispiel-*.html  einzelne Lösungen
<kurs>/pdf/         PDF je Beispiel
<kurs>/*_Kapitel_*.pdf, *_Loesungen_gesamt.pdf  Sammel-PDFs
material/           Angaben, Folien, alte Tests, Bücher
assets/             Stylesheet, Skripte, KaTeX
```

Die Seite ist rein statisch. Zum Ansehen `index.html` im Browser öffnen oder den Ordner mit einem beliebigen Webserver ausliefern.
